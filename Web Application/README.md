To run the backend, follow these steps:

1. Setup your environment for `app.env` based on the example
2. Run `make atlas-apply` to run migration
3. Open your terminal or command prompt.
4. Navigate to the directory where your `main.go` file is located. You can use the `cd` command to change directories.
5. Once you are in the correct directory, type `go run main.go` and press Enter.
6. The Go compiler will compile and run your `main.go` file, starting the backend server.
7. You should see the output or any error messages in the terminal.

That's it! Your backend should now be running. You can access it using the appropriate endpoints or URLs specified in your `main.go` file.

To run the front end of your application, follow these step:
1. Change direction to `Frontend`
2. Setup the environment based on the example
3. Make sure you are in the directory where your front end code is located. You can use the `cd` command to navigate to the correct directory.
4. Once you are in the correct directory, simply type `npm run dev` and press Enter.
5. This command will start the development server and scompile your front end code.
6. You should see the output or any error messages in the terminal.
7. Now you can access your front end application by opening a web browser and navigating to the appropriate URL or endpoint specified in your front end code.
